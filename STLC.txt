# Software-Testing
# - is the process of figuring out if the software is correct by looking at all of its properties and evaluating how software components run to find bugs, errors or other problems.

 # SDLC(Software Development Life Cycle)
 # - a process that sets up how software is made.
   
 ## SDLC Phases
# * Requirement Phase (analysing clients requirements)
# * Design Phase  (making a physical design & choosing tools to offer a platform on which sotware may run)
# * Build/Development phase (coding according to the design negotiated) 
# * Testing Phase  (final phase after developing the GUI and back end , we test the requirements from the requirements phase)
# * Deployment/Deliver phase  (clients can request any changes from the reuirement document or GUI improvement to make the programme more user-friendly)
# * Mantainance   (product care , when a consumer uses software problem arise and must be solved)
